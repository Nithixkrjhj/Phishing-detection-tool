# 🛡️ Phishing Attack Simulation & Detection System

## 📌 Overview
This project demonstrates how phishing attacks work and how they can be detected using simple techniques.

It includes:
- A simulated phishing login page
- A Python-based detection tool

---

## 🎯 Objective
To understand phishing techniques and build a basic system to detect malicious URLs and messages.

---

## 🛠️ Technologies Used
- Python
- HTML
- CSS

---

## ⚙️ Features
- Fake phishing login page (simulation)
- URL analysis (detects suspicious patterns)
- Keyword-based phishing detection
- Simple and effective CLI tool

---
